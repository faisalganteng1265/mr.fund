### Simulated versus public trigger evidence

A replay may be labelled **Simulated** while a genuine testnet repay transaction still executes, as P5.5 allows, but the deployed preferred Guardian reads actual configured prices and rechecks the trigger. A simulated watcher snapshot cannot bypass that check. Use an owner-approved valid policy and an actual observed below-trigger state, or record that bounded public acceptance is blocked. A sandbox replay proves only tested-locally behavior; it cannot close P5.5's network acceptance. A labelled operator request proves the contract path, not autonomous detection. Fixed-price assets may establish P0.2 partial pass but must not be assumed compatible with the currently configured Guardian trigger implementation without observation/D27 review.

Capture public factory/Guardian deployment/init/create, registration, activation, successful request, over-limit refusal, trigger callbacks, repay resolver, fee callback, owner borrow/repay/release/sweep and reserve withdrawal costs. Measure current build storage including configured history headroom and registration; retain failed-attempt costs. Report public testnet and local sandbox tables separately, with receipt gas reservations and remaining continuation margin rather than subtracting total burn from root gas and calling it available. D24 receives these observations and a separately labelled [I] estimate using explicitly sourced mainnet gas/storage inputs. No testnet number is automatically a mainnet cost/fee; founder chooses actual fee values and any real-money cap.
